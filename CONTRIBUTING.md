# Contributing

Thanks for considering a contribution to Paywall Buster.

## License

By submitting code, documentation, test data, or other material,
you agree that it may be distributed under the PolyForm
Noncommercial License 1.0.0 in `LICENSE`.

Only submit material that you created or have permission to
license. Do not contribute proprietary code, copied website
assets, access credentials, private data, or third-party
material without a compatible license.

## Project Scope

The project is source-available and limited to noncommercial
learning, research, and technical exchange. Contributions must
not add credentials, account bypasses, server-side access,
payload delivery, telemetry, or automatic download of remote
code.

## Pull Requests

- Keep changes focused and explain the user-visible behavior.
- Include a regression test or a reproducible test page when
  changing matching, scoring, repair, or advertising rules.
- Preserve the article and accessibility protections.
- Do not weaken CMP handling without a documented reason.
- Update `README.md` when behavior, permissions, or limitations
  change.
- Keep comments and documentation clear enough for review.

## Reporting Security Issues

Follow `SECURITY.md` instead of opening a public issue for a
vulnerability or privacy problem.
